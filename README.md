# ✦ 拾光星港

一款把现实中的自律兑换成快乐的本地小游戏：完成任务（读书、控制屏幕时间……）获得积分，用积分兑换现实里的奖励，把一片礁石建设成星港。

## 两种玩法

| | 本地版（推荐在电脑上用） | 网页版（GitHub Pages，手机也能玩） |
|---|---|---|
| 启动 | 双击 `启动游戏.command`（需要 python3） | 直接打开网址，手机上可「添加到主屏幕」 |
| 存档 | 本文件夹里的 `data.json`（自动备份） | 这台设备的浏览器里 |
| AI 鉴定 | 经本地服务转发 | 浏览器直接调用 DeepSeek |

两边的存档互相独立。要搬存档：设置 → 导出存档 / 导入存档（导出的文件不含 API Key）。

## 隐私
- `data.json`（存档和 API Key）已写进 `.gitignore`，不会被提交到 GitHub。
- 网页版的 API Key 只保存在你自己的浏览器里。

## 在另一台电脑上继续改
```bash
git clone <仓库地址>
cd <仓库文件夹>
python3 server.py     # 或双击 启动游戏.command
```

玩法说明见 [使用说明.md](使用说明.md)。
